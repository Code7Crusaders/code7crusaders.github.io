<h2>Verbale esterno AzzurroDigitale 17/10/2024</h2>

La riunione ha coperto i principali aspetti tecnici del progetto, inclusi la gestione del backend con OpenAI, database vettoriali e PostgreSQL come opzione. È stato discusso l'uso di Google Meet per la comunicazione e l'apertura a framework diversi da Angular. Sono state date indicazioni per integrare API di terze parti e modelli LLM, con enfasi sugli aspetti legati ai modelli linguistici. È stato suggerito di usare GitHub per il bug reporting e TDD per il testing.

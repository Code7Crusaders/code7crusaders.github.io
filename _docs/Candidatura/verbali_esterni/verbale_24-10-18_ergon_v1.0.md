<h2>Verbale esterno Ergon 18/10/2024</h2>

L'incontro ha chiarito che l’uso di .NET MAUI è opzionale, e l'azienda fornirà file con informazioni per l’LLM. Si è discusso l'uso di domande predefinite e AI generativa, con libertà di scelta sui modelli AI, inclusi quelli proprietari. È stato raccomandato il database RAG e l’uso del formato JSON per l’integrazione dati. Per il testing, si suggerisce una metodologia TDD e una comunicazione tramite Zoom per eventuali chiarimenti o incontri.

<h1>Analisi DB Vettoriale</h1>
<h2>Obiettivo</h2>
<p>Il seguente documento ha lo scopo di analizzare i database vettoriali e di fornire una valutazione per la scelta del database vettoriale più adatto per il progetto. Il documento è strutturato in tre sezioni principali:</p>
<ul>
    <li><strong>Introduzione ai database vettoriali:</strong> in cui vengono introdotti i database vettoriali e le loro caratteristiche principali.</li>
    <li><strong>Confronto:</strong> In maniera tabellare vengono confrontati i database vettoriali analizzati.</li>
    <li><strong>Conclusione e Motivazione della Scelta:</strong> in cui viene presentata la scelta del database vettoriale più adatto per il progetto in corso.</li>
</ul>

# Chi siamo

Code 7 Crusaders è un team di giovani sviluppatori entusiasti appassionati di coding e tecnologia. Siamo un gruppo di sette studenti dell'Università di Padova, dedicati all'apprendimento e alla crescita nel campo dell'informatica. Il nostro obiettivo è condividere le nostre conoscenze ed esperienze con altri interessati al coding e alla tecnologia. [Code 7 Crusaders GitHub](https://github.com/Code7Crusaders)

## Contatti generali
Per qualsiasi domanda o richiesta generale, puoi contattarci all'indirizzo email del team: [code7crusaders@gmail.com](mailto:code7crusaders@gmail.com).


## Contatti membri
